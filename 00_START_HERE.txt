🔧 CUSTOMIZATION GUIDE

To Add New Exercise:
1. Add to exercises object in js/app.js
2. Create new button with data-exercise attribute
3. Add styling if needed

To Extend Chatbot:
1. Add new topic to chatbotResponses in js/app.js
2. Add keyword check in generateBotResponse()
3. Include meaningful messages

To Change Colors:
1. Update color values in css/styles.css
2. Maintain WCAG AA contrast (4.5:1 minimum)
3. Test in browser

To Deploy:
1. Push to GitHub
2. Connect to Netlify or Vercel
3. Or upload via FTP to web host
4. Share URL with users
